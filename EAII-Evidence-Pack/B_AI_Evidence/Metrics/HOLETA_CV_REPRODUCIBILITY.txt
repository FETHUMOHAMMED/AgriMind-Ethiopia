SCOPE OF REPRODUCIBILITY VERIFICATION
================================================================================
This verification confirms:
  - Fold assignments are deterministic given seed=42 and sorted inputs
  - Detected duplicate clusters remain within single folds
  - Per-fold class representation is balanced
  - Model is freshly initialized per fold (no weight carryover)

This verification does NOT confirm:
  - Full training reproducibility across hardware or software versions
  - Data-loader ordering stability across PyTorch versions
  - Numerical determinism of CPU/GPU floating-point operations
  - Behavior under different torchvision or PIL versions

Full reproducibility requires pinning all dependency versions (torch,
torchvision, PIL, numpy, scikit-learn) and running on identical hardware.
That pinning is recommended for any future production training pipeline.
