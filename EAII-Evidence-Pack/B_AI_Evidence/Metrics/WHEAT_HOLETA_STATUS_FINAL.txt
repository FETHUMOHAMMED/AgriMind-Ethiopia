=== VERIFIED EVIDENCE ===

Public-trained wheat classifier:
  - Kaggle test set:      84.90% accuracy
  - Holeta field images:  34.15% accuracy (407 images)
  - Transfer gap:        +50.75 pp (poor transfer, documented)

Holeta-only experiments (5-fold CV on 407 Holeta images):
  - Standard stratified CV:        95.08% ± 1.75%
  - Leakage-free grouped CV:       95.56% ± 1.72%
  - Delta (grouped − standard):   +0.48 pp

Final production training (345/62 split): 95.16% val accuracy

Class-mapping verification: PASS
  All 3 scripts + checkpoint use identical CLASSES, class_to_idx,
  IMG_SIZE=128, ImageNet normalization.

Leakage audit:
  - Near-duplicate pairs detected (pHash Hamming <= 5/64, same-class): 2
  - Images with >=1 near-duplicate: 4 (1.0% of dataset)
  - Detected pairs crossing standard 5-fold boundaries: 1
  - Grouped CV (with detected clusters removed from training folds):
    95.56% +/- 1.72%  (vs standard 95.08% +/- 1.75%)

Interpretation of leakage audit:
  The grouped-CV experiment did not lower the measured mean accuracy,
  which is consistent with the two DETECTED near-duplicate pairs not
  accounting for the model's internal accuracy. This does NOT establish
  that leakage is negligible in general. Perceptual hashing detects only
  visual near-duplicates. Same-plant, same-plot, or same-session images
  photographed from different angles would not be detected by this
  method. The magnitude of leakage from such sources is unknown.

Reproducibility (verified via second run with seed=42):
  - Fold assignments identical across runs
  - Every duplicate cluster entirely within one fold (0 violations)
  - Class balance preserved across all folds
  - Model initialized fresh per fold (no weight carryover)

=== LIMITATIONS (honest) ===

1. pHash-based leakage detection catches ONLY visual near-duplicates.
   It cannot detect:
     - Same leaf photographed from different angles
     - Same plant, different leaves
     - Same field plot, different plants
     - Same acquisition session
   Grouped CV addresses only detected visual duplicates. True
   session-based or plot-based grouping requires metadata we do not
   have from the Holeta dataset.

2. Both CV experiments use images from a SINGLE location (Holeta wheat
   farm, Oromia). They measure within-dataset generalization only.
   They do NOT estimate generalization to:
     - Other Ethiopian farms
     - Other growing seasons
     - Other wheat varieties
     - Different cameras or lighting

3. The final production model (95.16% val on 62 images) has been
   trained on 345 images from the same 407-image collection. Its
   validation split is small and from the same source.

4. No independent test has been performed. The strongest remaining
   test would be: freeze the Holeta model, evaluate on expert-verified
   wheat images from a different Ethiopian collection (e.g., Kulumsa,
   Asella, or a different growing season).
